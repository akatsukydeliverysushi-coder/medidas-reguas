# Medidor de Tanques — PWA

Aplicativo web responsivo para calcular litros a partir da leitura da régua.

## Recursos
- Seleção visual das tabelas de 7.500, 10.000, 15.000, 20.000 e 30.000 L.
- Referência selecionada sempre visível.
- 30.000 L bipartido 15/15: leitura de um compartimento por vez, com tabela de 0 a 250 cm.
- Instalação como aplicativo (PWA).
- Funcionamento offline após a primeira abertura.
- Histórico local das últimas medições.
- Compartilhamento e cópia do resultado.

## Publicação
Envie todos os arquivos para a raiz do GitHub Pages e use `main` + `/ (root)`.

## Salvar em PDF
O botão **Salvar em PDF** abre a impressão do navegador. Escolha **Salvar como PDF** (ou equivalente no celular).
